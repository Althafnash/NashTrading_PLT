# NashTrading_PLT

## What is Nash Trading Platform

Nash trading Platform is a website dedicated to Analysis and data gathering for various markets such as BTC, Gold and EURUSD.

## Features

- Market data updated to a Minute timeframe
  
- Markets
  - EURUSD
  - GOLD
  - BTC
  
- FVG analysis for The EURUSD
  
- Historical data from 2015 for 500 companies in the S&P 500

## Tech Stack

### Development

* Python flask as a web sever
* postgres

### Production

* Vercel
* Neon
* Github
* Github pages
